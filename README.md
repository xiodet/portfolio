# Портфоліо лендингів

Приклади сайтів для локального бізнесу Києва. Кожен лендинг лежить у своїй папці, головна сторінка (`index.html`) згодом стане сайтом-візиткою зі всіма роботами.

| Папка | Що це |
|---|---|
| `salon/` | Концепт-салон краси «Mila Beauty Studio», Позняки |
| `flowers/` | Концепт квіткової майстерні «Bloom Lab», Печерськ |
| `barber/` | Концепт барбершопу «Ferrum Barbershop», Оболонь (темний вінтаж, латунь) |
| `barber-v2/` | Той самий барбершоп у сучасному стилі: чорний, синій акцент, великі вузькі заголовки |

Хостинг: GitHub Pages з гілки `main`, корінь репозиторію.

## salon/

Чистий HTML/CSS/JS без збірки. Відкрити локально: `cd salon && python3 -m http.server`.

- `config.js` — назва, телефон, соцмережі, карта, графік, налаштування запису.
- `data.js` — послуги з цінами, майстри, роботи в галереї, відгуки.
- `app.js` — логіка: прайс з вкладками, галерея з переглядом на весь екран, онлайн-запис.
- `img/` — фото з Pexels (безкоштовна ліцензія), стиснені до 1000–1600 px.

### Онлайн-запис → Telegram

Без налаштувань форма працює в демо-режимі: показує «Дякуємо, заявку отримано», нічого не надсилає.

Щоб заявки приходили в Telegram:
1. Створити бота через @BotFather, взяти токен.
2. Написати боту будь-що з потрібного акаунта/групи, взяти `chat_id` (наприклад, через `https://api.telegram.org/bot<TOKEN>/getUpdates`).
3. Для тесту: вписати `telegramBotToken` і `telegramChatId` у `config.js`.
4. Для реального клієнта краще не світити токен у коді сторінки: поставити безкоштовний Cloudflare Worker, який приймає JSON заявки і пересилає в Telegram, і вказати його адресу в `bookingEndpoint`.

## flowers/

Квіткова майстерня «Bloom Lab» (вигаданий бренд), яскравий, але не кислотний стиль (мʼякі фуксія, помаранчевий, лайм): шрифти Prata (заголовки) + Manrope (текст і цифри). Для порівняння шрифту заголовків: `?font=2` (Oranienbaum).

- `config.js` — контакти, адреса, графік доставки, Telegram (`orderEndpoint` або `telegramBotToken` + `telegramChatId`; порожньо = демо-режим).
- `data.js` — букети (ціна, привід, колір, стікер), квіти поштучно (фото, ціна за стебло, кольори, мінімум), зони доставки, відгуки.
- `app.js` — каталог з вкладками «Букети» / «Квіти поштучно», фільтри, кошик (localStorage; за квіти поштучно +150 ₴ збирання), оформлення з датою/часом, листівкою, анонімністю, оплатою.
- `img/` — StockSnap (CC0) і Wikimedia Commons (фон: Selena N. B. H., CC BY 2.0), обрізані до 4:5.

## barber/

Барбершоп «Ferrum Barbershop» (вигаданий бренд), Оболонь. Темний брутальний стиль з вінтажними деталями: чорний, дерево, латунь, зерно плівки. Шрифти Alumni Sans (заголовки) + Old Standard TT (курсивні підписи) + Manrope (текст). Для порівняння заголовків: `?font=2` (Oswald).

- `config.js` — контакти, адреса, години роботи, крок сітки часу, Telegram (`bookingEndpoint` або `telegramBotToken` + `telegramChatId`; порожньо = демо-режим).
- `data.js` — послуги з цінами за рівнем барбера `[барбер, старший, топ]`, барбери (рівень, вихідний день), галерея, відгуки, цифри.
- `app.js` — прайс-дошка, галерея з переглядом, онлайн-запис: послуга + додатки → барбер (ціна і найближче вікно кожного) → день і час (зайняті слоти, тривалість візиту) → квиток-підсумок, «Додати в календар» (.ics). Зайнятість у концепті генерується псевдовипадково; для реального клієнта тут підключається його CRM.
- `img/` — StockSnap (CC0): Nick Demou, Robin Vanden Berghe, Christoffer Engström, Skitter Photo, Matt Moloney, Jake Davies, Ryan McGuire, Hannes Wolf, Filipp Kozachuk, Caleb Morris, Bruce Mars.

## barber-v2/

Друга версія барбершопу Ferrum за референсом користувача (сучасний «преміум» барбершоп). Свій бренд, тексти і фото, код з нуля.

- Шрифти: Sofia Sans Extra Condensed 900 (заголовки капсом) + Inter (текст). Кольори: чорний `#08080A`, синій `#4F6BFF` / кнопки `#2C47D6`, золото `#E2BE72` для фірмового ритуалу, світла секція `#E9E6DF`.
- Анимації (без бібліотек): заголовок героя виїжджає рядками з-під маски, повільний zoom фото, поява блоків при скролі, лічильники, бігучий рядок, контурний текст що їде при скролі, два ряди відгуків назустріч (пауза при наведенні), FAQ-акордеон, пульсуюча кнопка чату. `prefers-reduced-motion` вимикає рух.
- Блоки: герой → бігучий рядок → «Більше, ніж стрижка» → фірмовий комплекс + VIP → меню-картки з вкладками → барбери → онлайн-запис (як у barber/) → відгуки → роботи → FAQ → фінальний заклик → футер.

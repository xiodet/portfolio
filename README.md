# Портфоліо лендингів

Приклади сайтів для локального бізнесу Києва. Кожен лендинг лежить у своїй папці, головна сторінка (`index.html`) згодом стане сайтом-візиткою зі всіма роботами.

| Папка | Що це |
|---|---|
| `salon/` | Концепт-салон краси «Mila Beauty Studio», Позняки |

Хостинг: GitHub Pages з гілки `main`, корінь репозиторію.

## salon/

Чистий HTML/CSS/JS без збірки. Відкрити локально: `cd salon && python3 -m http.server`.

- `config.js` — назва, телефон, соцмережі, карта, графік, налаштування запису.
- `data.js` — послуги з цінами, майстри, роботи в галереї, відгуки.
- `app.js` — логіка: прайс з вкладками, галерея з переглядом на весь екран, онлайн-запис.
- `img/` — фото з Pexels (безкоштовна ліцензія), стиснені до 1000–1600 px.

### Онлайн-запис → Telegram

Без налаштувань форма працює в демо-режимі: показує «Дякуємо, заявку отримано», нічого не надсилає.

Щоб заявки приходили в Telegram:
1. Створити бота через @BotFather, взяти токен.
2. Написати боту будь-що з потрібного акаунта/групи, взяти `chat_id` (наприклад, через `https://api.telegram.org/bot<TOKEN>/getUpdates`).
3. Для тесту: вписати `telegramBotToken` і `telegramChatId` у `config.js`.
4. Для реального клієнта краще не світити токен у коді сторінки: поставити безкоштовний Cloudflare Worker, який приймає JSON заявки і пересилає в Telegram, і вказати його адресу в `bookingEndpoint`.
